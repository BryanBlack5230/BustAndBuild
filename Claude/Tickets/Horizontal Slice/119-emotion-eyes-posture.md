## What to build

The one deliberate HS presentation exception — **readability is a system, not polish**: cursor-tracking eyes (Aware default, both factions, villagers included) + a distinct **posture per emotion state** (Suspicious slink, Scared cower/flee, Angry puff) on Visual Companions. Emote icons + tint remain; posture augments them.

## Acceptance criteria

- [ ] Aware units' eyes track the cursor
- [ ] Distinct readable posture per emotion, both factions, at battle zoom
- [ ] Icons + tint still present (augment, not replace)
- [ ] Readability check: a tester can call a unit's state with icons hidden
