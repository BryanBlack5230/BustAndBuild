## What to build

A grilling/design session producing specs for the **2–3 new shape-changing specials** that complete the enemy roster (7–8 total). Pure-endless mandate: long-run variety comes from combinatorics, so each new special must change battle **shape** — the way Digger rewrites pathing and Shaman rewrites sustain — not be a stat variant. Output per special: a DesignDoc section (behavior states, counters via the verbs, emotion-system interactions — event-edge only, no continuous checks — telegraphs, config knobs), its staged-intro Day, and preset-Group implications. Record new terms/ADR-worthy choices via `/domain-modeling`.

## Acceptance criteria

- [ ] 2–3 specials specced in DesignDoc with behaviors, counters, config knobs
- [ ] Each demonstrably changes battle shape (stated interaction with flick/PowerHit/defense/water)
- [ ] Emotion interactions defined event-edge; precedence rules respected
- [ ] Staged-intro Days + preset implications noted; glossary/ADR updated where needed
