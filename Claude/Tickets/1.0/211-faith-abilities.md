## What to build

The Faith ability set grows from HS's lightning to **3–5 castables**, with the hotbar scaling to match. Abilities are designed against the verbs — synergies with flick/PowerHit/water, not generic spells — and each earns a distinct battle role (no strict duplicates). Faith income (altar rates) vs ability costs balanced so casting is a real spend, not spam. Design-first: short spec per ability before building (mini 206-style pass, same session is fine).

## Acceptance criteria

- [ ] 2–4 new abilities castable in battle, Faith-costed, SO/config-defined
- [ ] Hotbar handles 3–5 abilities with cost/cooldown readouts
- [ ] Each ability has a distinct role; verb synergies stated in its spec
- [ ] Faith economy balanced: altar rate vs costs produces meaningful cast cadence
