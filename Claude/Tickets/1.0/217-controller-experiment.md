## What to build

The gated experiment, **timeboxed ~2 weeks, late production**: right-stick velocity flick vs Deck gyro-flick vs trackpad, each prototyped on the real battle loop (grab, flick, PowerHit, camera). Pass bar = testers call it **as good as mouse**. Pass → controller ships: control options, rebinding, glyphs. Fail → mouse-only ship, Deck unverified, controller revisited post-launch — the unsolved input problem does not hold the ship list hostage. Either way the verdict is recorded (ADR if it touched architecture).
