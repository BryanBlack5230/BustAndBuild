## What to build

Minimal-text onboarding per DesignDoc: **contextual one-liners on first encounters** ("Hold and flick!"), **diegetic affordances** (Beacon glow, villager pointing/prayer), tooltips in menus/shop UI. No tutorial mode, no guided island. First-encounter prompts cover the core verbs and key systems: grab/flick, PowerHit, Core insert, shop + staffing, Mounts, throwables, Faith casting — extendable as roster items land (new specials get their one-liner in their own tickets or a follow-up pass here). Prompts fire once per world, dismiss cleanly, never re-nag.

## Acceptance criteria

- [ ] One-liners for core verbs + key systems, trigger-on-first-encounter, config-listed
- [ ] Diegetic affordance pass done (Beacon glow etc. actually draw the eye)
- [ ] Tooltips across shop/menus/building panels
- [ ] No tutorial mode; prompts fire once, dismissible, persist as seen in the world save
